# TayMas Desk

Диспетчерская кампуса для двух кейсов хакатона:

1. разобрать входящие обращения — категория и черновик ответа;
2. отфильтровать алерты — оставить только `critical`.

Работает на своей машине. Python 3.10+, интернет и ключи не нужны.

---

## Быстрый старт

```bash
git clone https://github.com/BAITC-Hacks/hack-1ad92890-taymas-systems.git
cd hack-1ad92890-taymas-systems
python3 app.py
```

Откроется браузер: [http://127.0.0.1:8765](http://127.0.0.1:8765)

Если браузер не открылся сам — вставьте адрес вручную.

Остановить: `Ctrl+C` в терминале.

Другой порт:

```bash
python3 app.py --port 9000
python3 app.py --no-open          # сервер без браузера
```

## Как пользоваться диспетчерской

После запуска на экране два стола.

### Слева — входящие

В очереди уже лежат 5 обращений из задания. У каждого:

- категория: **справка** / **жалоба** / **другое**;
- черновик ответа на русском;
- **Скопировать ответ** — текст уходит в буфер, можно сразу вставить в почту;
- **Закрыть** — заявка гаснет и выпадает из счётчика «в очереди».

Новое письмо: вставьте текст в поле «Новое обращение» → **Разобрать** (или Enter). Категория и черновик появятся сверху очереди.

Примеры, что можно вставить:

- `Как получить справку о месте учёбы?` → справка
- `В столовой очередь, еда холодная.` → жалоба
- `Хочу записаться на консультацию завтра.` → другое
- `Пропал свет в аудитории 204` → жалоба

### Справа — мониторинг

По умолчанию включено **только critical**. Из 8 событий остаются три:

- disk 90%
- payment failed
- db timeout

В шапке: **критичных 3**. Шум (`user login`, `cpu 40%`, `heartbeat`, `cache miss`, `deploy ok`) скрыт.

Кнопка **все 8** показывает весь поток. **только critical** возвращает фильтр.

Верхние цифры — сводка смены: сколько в очереди, сколько жалоб, сколько критичных, сколько шума отсеяно.

## Бонус: живая смена

Три штуки для настроения, поверх обязательных двух кейсов:

- **Дежурный-барометр** в шапке (🐈 / 🐈‍⬛ / 🙀) — меняется от числа критичных алертов: спокоен → насторожен → в тревоге.
- **⚡ Симулировать инцидент** — кнопка в мониторинге подмешивает в поток случайное новое событие (backend отдаёт его через `POST /api/simulate`, без внешних сервисов). Если инцидент critical — экран мигает и играет синтезированная сирена (Web Audio API, без файлов).
- **Смена закрыта 🎉** — как только все обращения в очереди закрыты, экран салютует конфетти на `<canvas>` и показывает мини-отчёт смены (сколько обращений, жалоб и критичных поймано). Открой обращение обратно — праздник может повториться.

Всё это ванильный JS/CSS без сторонних библиотек — работает офлайн, там же, где и остальное приложение.

## Если нужен терминал, не браузер

```bash
python3 run.py          # оба кейса сразу
python3 classify.py     # только обращения
python3 filter.py       # только алерты
```

`classify.py` печатает категорию и черновик на каждое из 5 писем.  
`filter.py` печатает только critical и строку `критичных 3`.

## Что лежит в репозитории

| путь | зачем |
|------|--------|
| `app.py` | веб-диспетчерская |
| `web/` | страница, стили, скрипт |
| `data/messages.txt` | 5 готовых обращений |
| `data/events.json` | 8 событий (info / warn / critical) |
| `classify.py` | правила категорий и черновики |
| `filter.py` | фильтр `level == critical` |
| `run.py` | оба CLI-кейса подряд |
| `start.sh` | то же, что `python3 app.py` |

Категории считаются правилами (ключевые слова), без LLM и без агентов. «Симулировать инцидент», сирена и конфетти — тоже без сторонних сервисов: рандом на бэкенде плюс Web Audio/Canvas на фронте.
