# TayMas Systems — репетиция хакатона

Два лёгких кейса на обычных правилах, без агентов и внешних API. Python 3.10+, зависимости не нужны.

## Как запустить

```bash
python3 run.py            # оба кейса сразу
python3 classify.py       # только обращения
python3 filter.py         # только алерты
```

## 1. Классификатор обращений

Файл `data/messages.txt` — 5 готовых текстов. Скрипт для каждого печатает категорию (`справка` / `жалоба` / `другое`) и черновик ответа на русском. Категория — по ключевым словам.

Что получается:

| # | обращение | категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi‑Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | справка |

## 2. Фильтр алертов

Файл `data/events.json` — 8 событий (`info` / `warn` / `critical`). Скрипт оставляет только `critical` и печатает summary.

Что получается:

- disk 90%
- payment failed
- db timeout

`критичных 3`

## Ветки команды

| ветка | кто / что |
|-------|-----------|
| `feature/messages` | классификатор обращений |
| `feature/alerts` | фильтр алертов |
| `feature/docs` | README и общий запуск |
| `main` | всё вместе |
